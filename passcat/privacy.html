PassCat プライバシーポリシー

BirdRune（以下「当方」）は、パスワード管理アプリ「PassCat」（以下「本アプリ」）に おけるユーザー情報の取り扱いについて、以下のとおり定めます。

1. 基本方針

本アプリに登録されたパスワード等のデータは、暗号化されたうえで ユーザーの端末内に保存されます。 当方は、ユーザーのパスワードデータを保存・閲覧できるサーバーを運営していません。 クラウド同期を有効にした場合も、データの保存先は ユーザー自身のクラウドアカウントであり、当方がその内容にアクセスすることはありません。

2. 収集・利用する情報

  • メールアドレス — サインイン時の本人確認（ワンタイムコードの送信）にのみ使用します。 メールアドレスは暗号化されたデータの一部として端末内（および同期先のユーザー自身のクラウド）に 保存されます。当方が広告・マーケティング等の目的で利用することはありません。
  • 登録データ（パスワード等） — 暗号化して端末内に保存されます。 クラウド同期を有効にした場合、暗号化済みファイルのみがユーザー自身のクラウドへアップロードされます。
  • クラウド認証情報 — 各クラウドサービスへのアクセストークン、および WebDAV の接続情報（URL・ユーザー名・パスワード）は、暗号化して端末内に保存されます。

本アプリは、広告 SDK・アクセス解析 SDK・トラッキング SDK を使用していません。

3. 通信について

本アプリは、次の目的でのみネットワーク通信を行います。

  • サインイン用ワンタイムコードのメール送信
  • クラウド同期を有効にした場合の、選択したクラウドサービスとの暗号化ファイルの送受信
  • データの更新日時を正確に記録するための時刻取得（NTP）

4. クラウド同期と第三者サービス

クラウド同期は任意の機能であり、ユーザーが明示的に有効化した場合にのみ動作します。 各サービスへのアクセス範囲は次のとおりです。

  • Google Drive（Google LLC）— 本アプリが作成したファイルのみに アクセスできる drive.file スコープを使用します。 （Google プライバシーポリシー）
  • Dropbox（Dropbox, Inc.）— 専用のアプリフォルダのみにアクセスします。 （Dropbox プライバシーポリシー）
  • Box（Box, Inc.）— Box の仕様上、アカウント内のファイルの読み書き権限が 付与されますが、本アプリが操作するのは本アプリの保存ファイルのみです。 （Box プライバシーポリシー）
  • WebDAV — ユーザーが指定したサーバーの、指定 URL 直下の専用フォルダのみに アクセスします。接続は https に限定されます。

本アプリによる Google API から取得した情報の利用は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に準拠します。

5. 生体認証について

生体認証（指紋・顔認証）を選択した場合、認証処理は OS の機能によって行われます。 本アプリが指紋・顔などの生体情報そのものを取得・保存することはありません。

6. クリップボードについて

コピー機能を使用すると、選択した値が OS のクリップボードに格納されます。 クリップボードの内容は他のアプリから参照できる場合があるため、 貼り付け後は他の文字列で上書きすることをおすすめします。 本アプリがクリップボードの内容を外部へ送信することはありません。

7. データの削除

アプリ内のリセット機能により、端末内の保存データを削除できます。 クラウド上の保存ファイルは、同期先をローカルストレージへ切り替えた際に自動的に削除されるほか、 各クラウドサービス上から直接削除することもできます。

PassCat Privacy Policy

BirdRune ("we") describes below how user information is handled in the password manager application "PassCat" (the "App").

1. Our Approach

Passwords and other data registered in the App are stored encrypted on your device. We do not operate any server that stores or can read your password data. When cloud sync is enabled, data is stored in your own cloud account; we have no access to its contents.

2. Information We Collect and Use

  • Email address — used only to verify your identity at sign-in (sending a one-time code). It is stored as part of your encrypted data on your device (and in your own cloud if sync is enabled). We do not use it for advertising or marketing.
  • Registered data (passwords, etc.) — stored encrypted on your device. With cloud sync enabled, only the encrypted file is uploaded to your own cloud.
  • Cloud credentials — access tokens for cloud services and WebDAV connection details (URL, username, password) are stored encrypted on your device.

The App contains no advertising, analytics or tracking SDKs.

3. Network Communication

The App communicates over the network only for the following purposes:

  • Sending the one-time sign-in code by email
  • Transferring the encrypted file to/from your chosen cloud service, when cloud sync is enabled
  • Obtaining accurate time (NTP) to record data update timestamps

4. Cloud Sync and Third-Party Services

Cloud sync is optional and operates only when you explicitly enable it. The App's access to each service is as follows:

  • Google Drive (Google LLC) — uses the drive.file scope, which allows access only to files created by the App. (Google Privacy Policy)
  • Dropbox (Dropbox, Inc.) — accesses only a dedicated app folder. (Dropbox Privacy Policy)
  • Box (Box, Inc.) — due to how Box works, the App is granted read/write access to files in your account, but it only ever operates on its own save file. (Box Privacy Policy)
  • WebDAV — accesses only a dedicated folder under the server URL you specify. Connections are limited to https.

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Biometric Authentication

If you choose biometric sign-in (fingerprint / face recognition), authentication is performed by the operating system. The App never accesses or stores your biometric data itself.

6. Clipboard

When you use the copy feature, the selected value is placed on the OS clipboard. Clipboard contents may be readable by other apps, so we recommend overwriting the clipboard after pasting. The App never transmits clipboard contents anywhere.

7. Data Deletion

You can delete the data stored on your device using the in-app reset function. The save file in your cloud is deleted automatically when you switch sync back to local storage, and you can also delete it directly from your cloud service.
